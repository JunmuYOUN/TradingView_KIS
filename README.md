# KIS Tradingview

한국투자증권(KIS) Open API 시세로 차트를 띄우고, TradingView처럼 차트 위에 선을 긋는 개인용 웹 도구입니다.

- 차트: [Lightweight Charts](https://github.com/tradingview/lightweight-charts) v5 (Apache-2.0, `web/vendor`에 포함)
- 서버: Python FastAPI (KIS 키를 브라우저에 노출하지 않기 위해 서버를 거칩니다)
- KIS 키가 없으면 **MOCK(가짜 시세)** 로 실행되므로 바로 화면을 확인할 수 있습니다.

## 실행

### Windows

`TradingView.exe`를 실행하면 저장된 한투 연결을 확인합니다. 연결이 유효하면 한투 차트가 바로 열립니다. 로그인 창이 뜨면 KIS Developers의 App Key와 App Secret을 입력하거나 **데모로 시작**을 누르세요. 창을 닫거나 Esc를 눌러도 예시 시세로 데모 차트가 열립니다. 데모에서는 **계정 → 한투 API 로그인**으로 언제든 한투 시세로 전환할 수 있습니다.

앱이 모의·실전 환경을 확인하고 키를 암호화해 저장합니다. **계정 → 로그아웃**을 누르면 저장한 키와 토큰을 지우고 데모 차트로 돌아갑니다. Windows에서는 Microsoft Edge WebView2 런타임이 필요합니다.

국내 시세의 기본 거래소는 KRX입니다. 상단 **설정 → 국내 시세 거래소**에서 KRX, NXT 또는 KRX + NXT 통합을 선택하면 국내 차트에 바로 적용됩니다. **차트**를 누르면 차트 화면으로 돌아갑니다. 선택은 로그아웃하거나 앱을 다시 열어도 유지됩니다. 프로젝트 폴더에서 실행하면 `data/`에 저장한 선도 이어서 쓸 수 있습니다.

실행 파일을 다시 만들려면 Python 3.10 이상으로 `python -m venv .venv`를 실행한 뒤 PowerShell에서 `./build-desktop.ps1`을 실행합니다.

**브라우저:** `run.bat`을 더블클릭합니다. 처음 실행할 때 `.venv` 가상환경을 만들고 패키지를 설치하며, 이후에는 서버가 켜지고 브라우저가 열립니다.

### macOS / Linux

```bash
./run.sh
```

### 직접 실행

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m server.main
```

직접 실행하면 터미널에 표시된 일회용 주소를 브라우저에서 여세요. 주소를 처음 연 브라우저에 세션 쿠키를 발급합니다. 서버를 재시작하면 새 주소가 발급됩니다. 기본 접속은 이 PC의 루프백 주소입니다. 외부에서 접속하려면 `HOST`와 함께 `WEB_TLS_CERT`, `WEB_TLS_KEY`에 HTTPS 인증서와 개인 키의 경로를 지정하세요. `WEB_PUBLIC_HOST`에는 인증서와 일치하는 접속 호스트 이름을 지정할 수 있습니다.

### Android

안드로이드 앱의 소스와 Gradle 래퍼는 `android/`에 있습니다. APK는 이 프로젝트의 `server/`, `web/`, `desktop_login.py`를 함께 포함합니다. 처음 빌드할 때는 `android/README.md`의 도구 설치 절차를 따르세요. 이후 `./build-desktop.ps1`로 두 앱을 함께 빌드하거나 `./android/build-android.ps1 -NoInstall`로 APK만 만들 수 있습니다. 기존 설치의 SDK와 서명 키도 이어서 사용할 수 있습니다.

## KIS 키 연결

1. [KIS Developers](https://apiportal.koreainvestment.com)에서 API를 신청하고 App Key와 App Secret을 발급받습니다. 모의투자 키로도 시세를 받을 수 있습니다.
2. Windows에서는 데스크톱 앱의 **계정 → 한투 API 로그인**로 키를 넣는 방법을 권합니다. 키가 암호화되어 저장되고, `.env`에 키가 없으면 `run.bat`도 그 키를 씁니다. macOS/Linux에서 환경 파일로 설정하려면 `.env.example`을 `.env`로 복사하고 값을 채웁니다. 이 경우 키는 `.env`에 평문으로 남습니다.

   ```
   KIS_APP_KEY=발급받은키
   KIS_APP_SECRET=발급받은시크릿
   KIS_ENV=demo        # 실전 키라면 real
   KIS_MARKET=J        # KRX만: J / KRX+NXT 통합: UN
   ```
3. 서버를 다시 실행합니다. 국내 종목을 열었을 때 상단에 `KIS 모의 · KRX`처럼 인증 환경과 거래소가 표시됩니다.

`.env`와 `data/` 폴더(암호화한 키·토큰, 분봉 캐시, 그린 선)는 `.gitignore`에 들어 있어서 git에 올라가지 않습니다.

## 키와 토큰 보관

- App Key·App Secret(`data/kis_credentials.bin`), 접근토큰(`data/kis_token_*.bin`)은 Windows DPAPI로 **현재 Windows 사용자 계정**에 묶어 암호화합니다. 파일을 다른 계정이나 다른 PC로 복사하면 풀리지 않으므로, 옮긴 뒤에는 키를 다시 연결해야 합니다.
- 예전 버전이 `.env`에 평문으로 저장한 키는 Windows에서 새 버전을 처음 켤 때 암호화 저장소로 옮기고 `.env`에서는 값을 지웁니다. 평문 토큰 캐시(`data/kis_token_*.json`, `data/kis_approval_*.json`)는 서버를 켤 때 지웁니다. 이전 버전의 웹소켓 접속키 캐시도 정리합니다.
- Windows가 아닌 운영체제에서는 토큰을 디스크에 남기지 않고 메모리에만 둡니다. 그래서 서버를 다시 켜면 토큰을 새로 발급받습니다.

## 실시간 연결 보안

- 국내·미국 주식은 선택한 봉의 최신 가격과 거래량을 인증서 검증이 켜진 한투 HTTPS API에서 받습니다. 조회가 끝난 뒤 5초 후에 다시 조회하며, 오류가 반복되면 간격을 최대 60초까지 늘립니다. 갱신 사이의 개별 체결은 표시하지 않습니다.
- **앱 내부(창 ↔ 로컬 서버):** 로컬 서버는 다른 웹사이트가 보낸 요청(Origin·Sec-Fetch-Site 검사)과 DNS 리바인딩(Host 검사)을 거부합니다. 데스크톱 앱은 실행할 때마다 새 일회용 토큰으로 앱 창에만 세션 쿠키(HttpOnly, SameSite=Strict)를 주므로, 같은 PC의 다른 사용자나 프로그램은 실시간 웹소켓과 API에 붙을 수 없습니다.

## 사용법

### 과거 차트 조회

차트를 오른쪽으로 끌어 시간축의 왼쪽 끝에 가까워지면 이전 봉을 자동으로 불러옵니다. 국내·미국 주식과 지수의 일봉·주봉·월봉은 한투가 해당 종목과 거래소에 제공하는 과거 시세까지 볼 수 있습니다. 데모의 과거 가격은 가상 시세입니다.

NXT는 2025년 3월 4일에 거래를 시작했습니다. 그보다 오래된 국내 주식 차트는 **설정 → 국내 시세 거래소 → KRX**에서 조회하세요. [넥스트레이드 연혁](https://www.nextrade.co.kr/menu/history/menuList.do)

오래된 날짜를 볼 때는 일봉·주봉·월봉을 선택하세요. 국내주식 실전 분봉은 한투가 보관하는 최근 최대 1년까지, 국내주식 모의투자 분봉은 당일 시세를 조회합니다. 지수 분봉은 한투에서 받은 최근 구간을 표시합니다. [한국투자증권 국내주식 일별분봉 조회](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_time_dailychartprice/inquire_time_dailychartprice.py)

### 종목 검색

- 왼쪽 위 검색칸에 **종목명 일부**(`삼성`, `전자`), **초성**(`ㅅㅅㅈㅈ`), **코드 앞자리**(`0059`)를 입력하면 맞는 종목이 바로 아래에 나옵니다. 띄어쓰기와 영문 대소문자는 가리지 않습니다(`kodex200` → KODEX 200).
- `↑`/`↓`로 고르고 `Enter`로 엽니다. 결과가 뜨기 전에 `Enter`를 누르면 첫 번째 결과가 열리고, 6자리 코드는 그대로 열립니다. `Esc`는 닫기입니다.
- 순서: 이름이 그대로 같은 종목 → 이름이 그 글자로 시작하는 종목 → 코드 → 이름 중간에 들어 있는 종목 → 초성. 같은 수준에서는 전에 찾아본 종목, 주요 종목, 주식(ETF·ETN보다 먼저), 시가총액이 큰 종목 순서입니다.
- 종목 목록은 한국투자증권이 공개하는 종목 마스터(KOSPI·KOSDAQ·NASDAQ·NYSE·AMEX, 키 불필요)를 처음 실행할 때 받아 `data/symbols.json`에 저장하고 12시간마다 새로 받습니다. 받지 못하면 주요 종목과 검색 기록에 있는 종목만 이름으로 찾을 수 있고, 코드로는 언제든 열 수 있습니다. 내려받지 않으려면 `.env`에 `SYMBOL_DOWNLOAD=off`를 넣으세요.

### 해외주식 (미국)

- 검색칸에 **한글명**(`애플`, `테슬라`), **티커**(`AAPL`, `brk.b`), **영문명**(`apple`)을 입력해 고릅니다. 거래소까지 쓰면(`NAS:AAPL`, `NYS:KO`, `AMS:SPY`) 바로 열립니다. 목록에는 티커와 거래소(NASDAQ·NYSE·AMEX)가 함께 나옵니다.
- 가격은 달러로 소수 2자리(1달러 미만은 4자리)까지 표시합니다. 국내 종목으로 돌아오면 원 단위로 바뀝니다.
- 차트 시각은 **뉴욕 현지 시각**입니다. 분봉에는 시간외 거래(현지 04:00~09:30, 16:00~20:00)도 들어 있습니다.
- 미국 주식은 한투의 무료 미국 시세를 사용합니다. 한투는 이 API의 미국 시세를 0분 지연으로 안내하며, 앱은 5초 간격으로 확인합니다. [한국투자증권 해외주식 기간별 시세](https://apiportal.koreainvestment.com/apiservice-apiservice?/uapi/overseas-price/v1/quotations/dailyprice)
- 해외주식 시세는 KIS 계정에 해외주식 서비스가 신청되어 있어야 받을 수 있습니다. 모의투자 환경에서는 일부 시세가 제공되지 않을 수 있습니다.

### 국내·미국 지수

- 한투 로그인 후 `VIX`, `빅스` 또는 `공포지수`로 검색하면 **VIX 변동성 지수 · 미국 지수 · 한투**가 먼저 나옵니다. 한투 해외지수 코드 `VIX`로 현물지수 차트를 읽습니다. Yahoo Finance 시세는 `^VIX`로 별도 조회할 수 있습니다. [한국투자증권 해외지수 안내](https://securities.koreainvestment.com/main/customer/notice/Notice.jsp?cmd=TF04ga000002&num=47309)

- 종목 검색칸에 `코스피`, `코스닥150`, `나스닥`, `나스닥100`, `SPX` 등을 입력하고 **국내 지수** 또는 **미국 지수**로 표시된 결과를 선택하세요. 차트는 가격을 포인트(pt)로 표시합니다.
- 코스피, 코스닥, 코스피 200, 코스닥 150, 다우존스 30, 나스닥 종합, 나스닥 100, S&P 500은 앱에 기본으로 들어 있습니다. 한투 연결 후 종목 목록을 갱신하면 KRX 반도체와 필라델피아 반도체 지수 등도 검색할 수 있습니다. 로그인 없이 데모로 열면 내장 목록과 이전에 받은 목록을 사용하고 가상 시세를 표시합니다.
- 한투 실전은 일·주·월봉과 분봉, 한투 모의투자는 일·주·월봉을 제공합니다. 미국 지수의 당일 기간별 시세는 한투에서 제공하는 지연 시세 또는 종가입니다. 지수 분봉은 한 번에 최근 102개까지 받을 수 있습니다. 미국 지수의 큰 분봉은 수신한 1분봉을 합산하므로 처음에는 표시되는 봉이 적을 수 있습니다. [한국투자증권 해외지수 기간별 시세](https://apiportal.koreainvestment.com/apiservice-apiservice?/uapi/overseas-price/v1/quotations/inquire-daily-chartprice) · [해외지수 분봉](https://apiportal.koreainvestment.com/apiservice-apiservice?/uapi/overseas-price/v1/quotations/inquire-time-indexchartprice)

### Yahoo Finance 선물·환율·VIX

- 종목 검색칸에 **선물**, **환율**, **VIX**를 입력하고 Yahoo Finance로 표시된 항목을 선택하세요. 나스닥 100 선물(`NQ=F`), WTI 원유 선물(`CL=F`), 금 선물(`GC=F`), 원·달러 환율(`USD/KRW`), 변동성 지수(`^VIX`) 등을 한투 로그인 없이도 조회할 수 있습니다.
- Yahoo 일·주·월봉에서 차트 하단의 **날짜로 이동**을 눌러 연도(`1980`)나 날짜(`1980-01-02`)를 입력하세요. S&P 500(`^GSPC`)과 나스닥 종합(`^IXIC`)은 1980년 일봉을 제공합니다. 선택한 연도의 시세가 없으면 해당 종목의 첫 시세 날짜를 표시합니다.
- 기본 목록에 없는 선물·환율·지수는 Yahoo 티커를 그대로 입력하면 온라인으로 확인합니다. 예를 들어 커피 선물은 `KC=F`, 유로/엔 환율은 `EURJPY=X`, VIX 변동성 지수는 `^VVIX`로 찾을 수 있습니다.
- Windows 앱은 `yfinance`로, 안드로이드 앱은 Yahoo Finance 차트 서비스에 직접 연결해 봉을 가져옵니다. 선물 차트는 Yahoo가 해당 심볼에 제공하는 시계열을 표시합니다. 일·주·월봉과 분봉은 제공 기간 내에서 과거로 이동할 수 있습니다. 온라인 시세를 1분 간격으로 확인하며, 거래소별 지연과 분봉 보관 기간이 적용됩니다. [Yahoo Finance 거래소별 데이터 안내](https://help.yahoo.com/kb/finance/article-exchanges-data-delays-sln2310.html)
- 차트 왼쪽 위에 제공처가 확인한 지연 시간을 **10분 지연**처럼 표시합니다. 시간 없이 지연만 확인되면 **지연 시세**, 장이 닫혔으면 거래 상태도 함께 표시합니다. 분봉의 **최근 시세 N분 전**은 마지막으로 보고된 시세의 실제 경과 시간입니다.

### 검색 기록

- 검색해서 연 종목은 `data/search_history.json`에 최근 20개까지 저장되어, 앱을 다시 켜도 남습니다. 데스크톱 앱과 `run.bat`이 같은 기록을 씁니다.
- 검색칸을 누르면 **최근 검색**이 나옵니다. 항목 오른쪽 `×`로 하나씩, **전체 삭제**로 한꺼번에 지울 수 있습니다.

### 차트 유형과 지표

- **설정 → 종목 변경 시 가격축 자동 맞춤**은 기본으로 켜져 있습니다. 종목을 바꾸면 오른쪽 가격축이 새 종목에서 보이는 봉의 가격대에 맞춰집니다. 직접 조정한 가격축을 다음 종목에서도 유지하려면 체크를 해제하세요.
- 상단에서 시간 간격 옆의 캔들 아이콘을 눌러 차트 유형을 선택합니다. 합성 가격으로 그리는 유형은 계산 기준을 상단에 표시합니다. 원래 봉의 시각을 사용해 그려 둔 선과 지표의 위치를 맞춥니다.
- **지표** 또는 `/`로 지표 창을 엽니다. 이름이나 약어를 검색한 뒤 결과를 누르면 현재 종목에 적용됩니다. 별표로 즐겨찾기를 변경하고, 상단 **지표** 옆 화살표로 즐겨찾기를 바로 열 수 있습니다. 차트에서 지표 이름 옆의 톱니바퀴로 기간·색을 바꾸고 **×**로 제거합니다.
- **일목균형표** 또는 `Ichimoku`를 검색하면 주식·지수 차트에 전환선, 기준선, 후행스팬, 구름대가 표시됩니다. 기본 기간은 전환선 9봉, 기준선 26봉, 선행스팬 B 52봉입니다. 선행스팬 A·B는 계산한 위치에서 26봉 앞으로, 후행스팬은 종가를 26봉 뒤로 옮겨 표시합니다. 톱니바퀴에서 기간, 이동 봉 수, 색상을 변경할 수 있습니다. 구름대는 두 선행스팬을 모두 계산할 봉이 쌓이면 나타납니다.
- **내 스크립트**에 `plot(ta.sma(close, 20))`처럼 가격·거래량을 사용하는 단일 수식을 저장해 차트에 표시할 수 있습니다. 편집기에 지원 문법이 표시됩니다. 개인 스크립트와 즐겨찾기는 이 앱의 로컬 저장소에 보관합니다.
- 시간 가격 기회(TPO)는 30분 이하 분봉으로 집계합니다. 세션 볼륨 프로파일은 각 봉의 거래량을 해당 고가·저가 구간에 배분한 추정치입니다. 볼륨 풋프린트와 레인지에는 현재 한투 연결이 제공하는 봉보다 세밀한 체결 데이터가 필요합니다.
- 상단 **얼러트**에서 목표 가격을 등록하거나 현재 종목의 얼러트를 확인하고 삭제할 수 있습니다. **지표 이름 옆 ⚙ → 얼러트**에서 이동평균선이나 볼린저 밴드의 상단·중앙·하단을 선택하세요. RSI 같은 보조지표는 선택한 지표선이 통과할 기준값을 입력합니다.
- 차트에 그린 **추세선·연장선·수평선**은 선을 선택한 뒤 편집창에서 **얼러트**를 누릅니다. 추세선은 두 점 사이를 감시합니다. 두 번째 점 너머까지 감시하려면 연장선을 사용하세요.
- 얼러트는 기본으로 앱에 한 번 표시됩니다. **계속 알림**을 체크하면 선택한 방향으로 다시 돌파할 때마다 알림이 표시됩니다. 등록한 뒤에도 얼러트 목록에서 체크하거나 해제할 수 있습니다.
- 지표·그리기 얼러트는 등록한 종목과 봉 주기의 실시간 차트에서 작동합니다. 지표나 선을 삭제하면 연결된 얼러트도 삭제됩니다.
- 조회가 끊겼다가 다시 연결되면 마지막으로 확인한 봉부터 시세를 이어 받아 봉별로 돌파를 확인합니다. 제공처에서 그 구간을 복구할 수 없으면 차트에 **시세 공백 있음**을 표시하고 새 기준값부터 알림을 재개합니다.
- **리플레이**에서는 시작 봉을 선택하고 과거 봉을 한 개씩 넘기거나 연속 재생할 수 있습니다. **실시간으로**를 누르면 최신 봉으로 돌아갑니다.

### 선긋기 도구

왼쪽 도구막대의 **+**에서 도구 종류, 이름, 스타일을 정하고 **도구막대에 추가**를 누르세요. 사각형·타원·삼각형·수직선·화살표를 추가하거나, 같은 도구를 서로 다른 스타일로 여러 개 저장할 수 있습니다. 같은 창의 목록에서 저장한 도구를 수정하거나 제거할 수 있습니다. 이미 그린 도형은 그릴 때의 스타일을 유지합니다.

| 도구 | 단축키 | 점 개수 |
|---|---|---|
| 선택 / 이동 | V | |
| 추세선 | T | 2 |
| 연장선(오른쪽으로 무한) | R | 2 |
| 수평선 | H | 1 |
| 피보나치 되돌림 | F | 2 (시작점 = 1, 끝점 = 0) |
| 평행 채널 | C | 3 (기준선 2점 + 폭 1점) |
| 엘리엇 충격파 | E | 6 (0, 1, 2, 3, 4, 5) |
| 엘리엇 조정파 | A | 4 (0, A, B, C) |

- 왼쪽 막대에서 추세선을 누르면 색, 굵기, 선 종류를 먼저 정할 수 있습니다. 도구별 설정은 다음에 그릴 때도 유지됩니다. 기존 선을 클릭하면 그 선의 스타일을 편집합니다. 아이콘 옆 화살표로 연장선·수평선·평행 채널과 파동 도구를 펼칩니다.
- 도구 목록의 별표를 누르면 왼쪽 막대에 해당 도구가 추가됩니다. 브러시 옆 화살표에서 사각형·타원·삼각형·화살표를 바로 선택할 수 있습니다.
- 도구를 고른 뒤 차트를 클릭해 점을 찍습니다. 브러시는 누른 채 끌고, 텍스트와 아이콘은 한 번 클릭해 배치합니다. **계속 그리기**를 켜면 같은 도구로 연이어 그릴 수 있습니다.
- 선을 클릭하면 선택되고, 끌면 통째로 이동합니다. 선택한 선의 동그란 점을 끌면 그 점만 움직입니다.
- `Delete` 삭제, `Ctrl+Z` 되돌리기, `Esc` 그리기 취소입니다.
- **자석**을 켜 두면 점이 가장 가까운 시가·고가·저가·종가에 붙습니다.
- 충격파는 기본 규칙(2파가 1파 시작점을 넘지 않음, 3파가 가장 짧지 않음, 4파가 1파 영역과 겹치지 않음)을 검사해서 어긋나면 경고를 표시합니다.
- 선은 (시각, 가격)으로 저장되므로 타임프레임을 바꿔도 같은 자리에 남습니다. 종목별로 `data/drawings/<종목코드>.json`에 자동 저장됩니다.
- 전송 대기 중인 편집은 같은 브라우저의 로컬 저장소에 보관하고 다음 실행에서 저장을 다시 시도합니다. 두 창이 같은 종목의 그림을 수정하면 저장 상태 옆에서 유지할 버전을 고를 수 있습니다.

## 다른 컴퓨터에서 쓰기

```bash

cd KIS_Tradingview
```

그린 선까지 컴퓨터 사이에서 공유하고 싶다면 `.gitignore`에 `!data/drawings/` 한 줄을 추가하고 커밋하면 됩니다.

### 사용하는 KIS API

| 용도 | TR | 1회 최대 |
|---|---|---|
| 일·주·월봉 | FHKST03010100 `inquire-daily-itemchartprice` | 100건 |
| 당일 분봉 | FHKST03010200 `inquire-time-itemchartprice` | 30건 |
| 과거 분봉 (최대 1년) | FHKST03010230 `inquire-time-dailychartprice` | 120건 |
| 해외 일·주·월봉 | HHDFS76240000 `overseas-price/.../dailyprice` | 100건 |
| 해외 분봉 (1·3·5·15·30·60분) | HHDFS76950200 `overseas-price/.../inquire-time-itemchartprice` | 120건 |
| 국내 지수 일·주·월봉 | FHKUP03500100 `inquire-daily-indexchartprice` | 50건 |
| 국내 지수 분봉 | FHKUP03500200 `inquire-time-indexchartprice` | 102건 |
| 미국 지수 일·주·월봉 | FHKST03030100 `overseas-price/.../inquire-daily-chartprice` | 날짜 범위 지정 |
| 미국 지수 분봉 | FHKST03030200 `overseas-price/.../inquire-time-indexchartprice` | 102건 |

- 접근토큰은 하루 동안 유효하고 1분에 1회만 발급되므로 `data/kis_token_*.bin`에 암호화해 캐시합니다.
- 초당 호출 제한(실전 20건, 모의 5건)을 넘지 않도록 서버가 호출 간격을 조절합니다.
- 지난 날짜의 분봉은 `data/cache/`에 저장해 두므로, 같은 종목은 두 번째부터 빠르게 열립니다.
- 국내 3·5·15·30·60분봉은 1분봉을 서버에서 묶어서 만듭니다. 해외 분봉은 KIS에서 그 분봉 그대로 받습니다(60분봉 15일치가 2번 호출). 분봉의 기본 조회 기간은 `server/main.py`의 `DEFAULT_DAYS`에서 바꿀 수 있습니다.

## 알려진 제한

- KIS 연동 코드는 공식 예제(koreainvestment/open-trading-api)의 파라미터를 기준으로 작성했습니다. 새 HTTPS 주기 조회와 로그인·로그아웃 흐름은 테스트용 API 응답으로 검증했습니다.
- 미래 영역에 찍은 분봉 점은 장 마감과 휴장 시간을 고려하지 않고 연속 시간으로 계산합니다. 일봉은 주말을 건너뜁니다.
- 볼륨 풋프린트와 레인지 차트에는 개별 체결 데이터가 필요합니다. 현재 앱의 과거 시세는 OHLCV 봉으로 제공됩니다.
- 국내·미국 지수 목록은 한투가 공개한 지수 마스터 파일로 검증했습니다. 주식 목록은 공식 파일 형식에 맞춘 테스트 데이터로 검증했습니다.
- KONEX 종목과 ELW는 검색 목록에 없습니다(코드로는 열 수 있습니다).
- 해외는 미국(NASDAQ·NYSE·AMEX)만 지원합니다. 홍콩·일본·중국·베트남은 KIS가 같은 방식의 API를 제공하므로 같은 구조로 추가할 수 있습니다. 미국 종목 마스터 파일은 공식 예제 형식으로 만든 테스트 데이터로만 확인했습니다.
